1. Základní principy

Co je datový soubor?

Soubor slouží k ukládání údajů, aby nám zůstaly i po vypnutí programu.

V C# nejčastěji pracujeme se dvěma typy:

Textový soubor .txt Binární soubor .dat

Textový vs. binární soubor

TextovýBinární
Čitelný člověkemNení běžně čitelný
StreamReaderBinaryReader
StreamWriterBinaryWriter
ReadLine()ReadInt32()
WriteLine()Write()

Zapamatuj si!

Text = StreamReader / StreamWriter

Binární = BinaryReader / BinaryWriter

Přípona .dat automaticky neznamená binární soubor. Rozhoduje způsob, jakým jsou data uložena.

using

using (FileStream fs = new FileStream("cisla.dat", FileMode.Open))
{
    // Práce se souborem
}

using automaticky zavře soubor po dokončení bloku. Nemusíš ručně volat Close().

2. Textové soubory

Čtení textového souboru

using (StreamReader sr = new StreamReader("cisla.txt"))
{
    while (!sr.EndOfStream)
    {
        string radek = sr.ReadLine();
        listBox1.Items.Add(radek);
    }
}

StreamReader čte text.

ReadLine() přečte jeden řádek.

EndOfStream pozná konec souboru.

Zápis do textového souboru

using (StreamWriter sw = new StreamWriter("vystup.txt"))
{
    sw.WriteLine("Ahoj");
    sw.WriteLine("123");
}

WriteLine() zapíše text a přejde na nový řádek.

Přidání na konec souboru

using (StreamWriter sw = new StreamWriter("cisla.txt", true))
{
    sw.WriteLine("Novy radek");
}

true znamená přidat na konec, ne přepsat celý soubor.

false znamená přepsat soubor.

Rozdělení řádku pomocí Split

Například máme v souboru:

Jan Novak;muz;85
string[] udaje = radek.Split(';');

string jmeno = udaje[0];
string pohlavi = udaje[1];
int vaha = int.Parse(udaje[2]);

Split(';') rozdělí řádek podle středníku.

IndexHodnota
udaje[0]Jan Novak
udaje[1]muz
udaje[2]85

Převod textu na číslo

int cislo = int.Parse(radek);

Parse převede text na číslo, ale při neplatném textu může vyhodit chybu.

if (int.TryParse(radek, out int cislo))
{
    // Tady je cislo platne
}

TryParse bezpečně zkusí převod. Pokud se převod nepovede, vrátí false.

3. Binární soubory

BinaryWriter – zápis

using (FileStream fs = new FileStream("cisla.dat", FileMode.Create))
{
    using (BinaryWriter bw = new BinaryWriter(fs))
    {
        bw.Write(10);
        bw.Write(20);
        bw.Write(30);
    }
}

BinaryWriter zapisuje hodnoty binárně.

BinaryReader – čtení

using (FileStream fs = new FileStream("cisla.dat", FileMode.Open))
{
    using (BinaryReader br = new BinaryReader(fs))
    {
        while (br.BaseStream.Position < br.BaseStream.Length)
        {
            int cislo = br.ReadInt32();
            listBox1.Items.Add(cislo);
        }
    }
}

Position = aktuální pozice v souboru.

Length = celková délka souboru.

Cyklus běží, dokud jsme nedošli na konec.

POZOR – typy musí souhlasit!

ZápisČtení
bw.Write(int)br.ReadInt32()
bw.Write(double)br.ReadDouble()
bw.Write(float)br.ReadSingle()
bw.Write(bool)br.ReadBoolean()
bw.Write(char)br.ReadChar()

Co zapíšu, to stejně přečtu!

FileMode – režimy souboru

RežimVýznam
CreateVytvoří nebo přepíše soubor.
OpenOtevře existující soubor.
AppendOtevře nebo vytvoří soubor a zapisuje na konec.
CreateNewVytvoří nový soubor, pokud ještě neexistuje.
OpenOrCreateOtevře nebo vytvoří soubor.

File.Exists – kontrola existence

if (File.Exists("cisla.dat"))
{
    // Soubor existuje
}
else
{
    MessageBox.Show("Soubor neexistuje");
}

FileStream – důležité vlastnosti

  • fs.Position – aktuální pozice.
  • fs.Length – velikost souboru.
  • fs.Position = 0 – návrat na začátek.
  • fs.Position = fs.Length – přesun na konec.

4. Typické úlohy z tvých kódů

A) Převod textového souboru na binární

Načteme čísla z TXT a uložíme je do DAT.

using (StreamReader sr = new StreamReader("cisla.txt"))
{
    using (FileStream fs = new FileStream("cisla.dat", FileMode.Create))
    {
        using (BinaryWriter bw = new BinaryWriter(fs))
        {
            while (!sr.EndOfStream)
            {
                string radek = sr.ReadLine();

                if (int.TryParse(radek, out int cislo))
                {
                    bw.Write(cislo);
                }
            }
        }
    }
}

Postup: přečtu řádek → převedu na číslo → zapíšu binárně.

B) Výpočet průměru

double n = double.Parse(textBox1.Text);
double soucet = 0;

for (int i = 0; i < n; i++)
{
    double cislo = br.ReadDouble();
    soucet += cislo;
}

double prumer = soucet / n;

Průměr = součet všech čísel / počet čísel.

Pozor: soubor musí obsahovat double hodnoty a počet n nesmí být nula.

C) Výpis každého druhého čísla

int poradi = 1;

while (br.BaseStream.Position < br.BaseStream.Length)
{
    int cislo = br.ReadInt32();

    if (poradi % 2 == 0)
    {
        listBox1.Items.Add(cislo);
    }

    poradi++;
}

% znamená zbytek po dělení.

poradi % 2 == 0 znamená sudé pořadí.

poradi++ zvýší pořadí o jedna.

Čísla: 10, 20, 30, 40, 50
Výpis: 20, 40

D) Hledání největšího čísla

int max = int.MinValue;

while (br.BaseStream.Position < br.BaseStream.Length)
{
    int cislo = br.ReadInt32();

    if (cislo > max)
    {
        max = cislo;
    }
}

int.MinValue je nejmenší hodnota typu int.

Pokud najdeme větší číslo, uložíme ho do max.

E) Prohození maxima s posledním číslem

Nejdříve si při čtení uložíme pozici největšího čísla a jeho hodnotu.

long max_pozice = 0;
int max = int.MinValue;
int posledni = 0;

while (br.BaseStream.Position < br.BaseStream.Length)
{
    long aktualni_pozice = fs.Position;
    int cislo = br.ReadInt32();

    if (cislo > max)
    {
        max = cislo;
        max_pozice = aktualni_pozice;
    }

    posledni = cislo;
}

Potom zapíšeme poslední číslo na místo maxima a maximum na konec:

fs.Position = max_pozice;
bw.Write(posledni);

fs.Position = fs.Length - 4;
bw.Write(max);
Proč -4?

Protože jedno číslo typu int zabírá 4 bajty. Tohle platí pro soubor složený z hodnot int32.

F) Prvočísla

Prvočíslo je číslo větší než 1, které je dělitelné pouze 1 a samo sebou.

public bool JePrvocislo(int c)
{
    if (c < 2)
    {
        return false;
    }
    else
    {
        for (int d = 2; d < c; d++)
        {
            if (c % d == 0)
            {
                return false;
            }
        }

        return true;
    }
}

Pokud zbytek po dělení vyjde 0, číslo není prvočíslo.

c % d == 0 = číslo je dělitelné beze zbytku.

G) Rozdělení sportovců na muže a ženy

if (udaje[1] == "muz")
{
    muzi.WriteLine(radek);
}
else
{
    zeny.WriteLine(radek);
}

Podle druhého údaje poznáme pohlaví a řádek zapíšeme do příslušného souboru.

H) Vyhledání jména Svoboda

if (udaje[0].Contains("Svoboda"))
{
    listBox2.Items.Add(radek);
}

Contains kontroluje, jestli text obsahuje zadaný řetězec.

Například najde „Tomas Svoboda“ i „Anna Svobodova“.

I) Otevření a uložení souboru přes dialog

if (openFileDialog1.ShowDialog() == DialogResult.OK)
{
    string cesta = openFileDialog1.FileName;
}

OpenFileDialog umožní vybrat soubor.

SaveFileDialog umožní vybrat, kam uložit nový soubor.

FileName obsahuje cestu k vybranému souboru.

5. Nejčastější chyby u písemky

❌ Špatný typ při čtení

bw.Write(10.5);
int cislo = br.ReadInt32();

Špatně! Zapsal jsi double, ale čteš int.

✓ Správně: br.ReadDouble()

❌ Zapomenuté Position = 0

Pokud jsi do souboru zapisoval a chceš ho následně číst, musíš se vrátit na začátek.

fs.Position = 0;

❌ Špatné umístění poradi++

if (poradi % 2 == 0)
{
    poradi++;
}

Špatně – pořadí se zvýší pouze při splnění podmínky.

✓ poradi++ patří mimo if, ale dovnitř cyklu.

❌ Soubor už neexistuje

Před otevřením souboru pro čtení můžeš ověřit:

if (File.Exists("cisla.dat"))
{
    // cteni souboru
}

❌ Soubor je stále otevřený

Nemůžeš bez rozmyslu současně číst a zapisovat do stejného souboru přes různé streamy.

Nejdřív dokonči čtení a zavři stream pomocí using, potom soubor znovu otevři pro zápis.

Další věci, na které nezapomenout

  • Vymazat ListBox před novým načtením: listBox1.Items.Clear();
  • Ověřit existenci souboru.
  • U čísel použít Parse nebo TryParse.
  • Nezapomenout na i++ nebo poradi++.
  • Správně nastavit FileMode.
  • Nezaměnit indexy pole – první je vždy 0.

6. Mini test před písemkou

Zkus si odpovědět bez koukání. Kliknutím zobrazíš odpověď.

1. Jaký příkaz čte textový soubor?

StreamReader

2. Jaký příkaz zapisuje binární data?

BinaryWriter

3. Jak přečtu celé číslo int ze souboru?

br.ReadInt32()

4. Jak zapíšu desetinné číslo typu double?

bw.Write(cislo);

5. Co znamená FileMode.Create?

Vytvoří soubor, případně přepíše existující.

6. Co znamená FileMode.Open?

Otevře již existující soubor.

7. Jak zjistím, jestli soubor existuje?

File.Exists("cisla.dat")

8. Co dělá ReadLine()?

Přečte jeden řádek textového souboru.

9. Co dělá Split(';')?

Rozdělí text podle středníku na jednotlivé části pole.

10. Co znamená Position?

Aktuální pozice v souboru.

11. Co znamená Length?

Celková délka souboru v bajtech.

12. Jak se vrátím na začátek souboru?

fs.Position = 0;

13. Co dělá TryParse?

Bezpečně zkouší převést text na číslo a vrací true nebo false.

14. Jak zjistím každé druhé pořadí?

poradi % 2 == 0

15. Co znamená int.MinValue?

Nejmenší možná hodnota typu int. Hodí se jako počáteční hodnota při hledání maxima.

16. Jak přidám text na konec souboru?

new StreamWriter("soubor.txt", true)

17. Co dělá using?

Po dokončení bloku automaticky zavře používaný soubor nebo stream.

18. Co znamená % v C#?

Zbytek po dělení.

Rychlé opakování – zapamatuj si těchto 8 věcí

  1. Text = StreamReader / StreamWriter.
  2. Binární = BinaryReader / BinaryWriter.
  3. int = ReadInt32().
  4. double = ReadDouble().
  5. Create = vytvořit nebo přepsat.
  6. Open = otevřít existující.
  7. Position = aktuální pozice.
  8. Length = délka souboru.
